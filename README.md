Professional frontend portfolio built with **Next.js** and **Tailwind CSS**.

## Core Stack

- React
- Next.js
- JavaScript
- Tailwind CSS
- HTML5
- CSS3
- REST APIs
- Git / GitHub

## Featured Projects

1. **Velvety Cupcakes Storefront** — Next.js + Tailwind CSS
2. **Velvety Admin Dashboard** — React + Tailwind CSS
